# landing_creative_practice
This project is a landing page for the "Frontend Basics: HTML &amp; CSS" online course.

It is designed to present course details, introduce the instructor, and provide a clear overview of the program structure. The page also includes a registration form and links to related resources.

Technologies: HTML5, CSS3, Responsive layout, Semantic markup and structured content blocks.

Features:
- Multi-section layout with clear information hierarchy
- Styled registration form for course enrollment
- List of theory and practical modules
- Smooth in-page navigation
- User interface in Ukrainian
